# Code Review

## Syfte

Code review används för att kontrollera kodkvalitet
och dela kunskap mellan utvecklare.

## Riktlinjer

- Skriv tydliga commit-meddelanden.
- Testa koden innan du skapar en Pull Request.
- Kör relevanta automatiserade tester.
- Kontrollera att projektet går att bygga utan fel.
- Dokumentera viktiga ändringar.
