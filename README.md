## Vanliga Git-kommandon

| Kommando        | Beskrivning                        |
| --------------- | ---------------------------------- |
| `git status`    | Visar aktuella ändringar           |
| `git switch -c` | Skapar och byter till en ny branch |
| `git add`       | Lägger till ändringar i staging    |
| `git commit`    | Sparar en commit lokalt            |
| `git push`      | Skickar commits till GitHub        |
| `git pull`      | Hämtar och integrerar ändringar    |
